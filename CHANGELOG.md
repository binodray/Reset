# Changelog

All notable changes to Reset are listed here. Versions follow [Semantic Versioning](https://semver.org).

## [1.0.8] - 2026-10-08

### Changed
- New dark installer that matches the app: dark title bar, pages, buttons and progress bar, with Reset artwork on the welcome and finish pages.
- Simplified app icon: the clock hand is gone, leaving a clean reset arrow.

## [1.0.7] - 2026-10-07

### Added
- Settings → FAQ & About, with answers about the clock, sessions, resizing, the tray icon, reminders and sharing. About shows the installed version.

### Changed
- Saving a new focus or break duration updates that countdown immediately. A running countdown keeps running and a paused one stays paused. Other preference changes no longer restart the countdown.

## [1.0.6] - 2026-10-07

### Changed
- Reset lives in the notification area only, with no taskbar button, including while Settings or a break reminder is open. Left-click the icon to show the widget; right-click for timer actions, Settings and Exit.

## [1.0.5] - 2026-10-07

### Changed
- Centred play controls and a text-only card header.
- The resize indicator only appears when its corner is hovered.
- Settings opens directly, without briefly showing the break reminder.
- Larger cards can show gentle focus messages (Settings → Card text).

## [1.0.4] - 2026-10-07

### Fixed
- Native dragging and resizing now use a regular interactive Windows window.

## [1.0.0] - 2026-10-07

- First release: flip-clock focus timer, break reminders, settings, accent colours, light and dark themes, resizable widget and tray integration.
